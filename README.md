# Cisco Packet Tracer Network Labs

A collection of Cisco Packet Tracer exercises covering the progressive construction and configuration of network topologies during the ETNA networking curriculum.

## Contents

The `.pkt` files are organized by exercise stage, from `teixei_t_etape1.pkt` through `teixei_t_etape13.pkt`. Each file represents a network configuration checkpoint and can be opened with Cisco Packet Tracer.

## How to Use

1. Install a compatible version of Cisco Packet Tracer.
2. Clone or download this repository.
3. Open the required `.pkt` file in Packet Tracer.
4. Review the topology, device configuration and connectivity at that stage.

```text
git clone https://github.com/TeixeiraThomas/Reseau-Packet-Tracer.git
```

## Learning Topics

Depending on the exercise, the labs cover topology design, addressing, switching, routing, device configuration and connectivity troubleshooting.
