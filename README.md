# Cisco Packet Tracer Network Labs

A structured collection of Cisco Packet Tracer exercises covering the progressive design, configuration and troubleshooting of network topologies during the ETNA networking curriculum.

## Learning Progression

```mermaid
flowchart LR
    A[Topology basics] --> B[Addressing]
    B --> C[Switching]
    C --> D[Routing]
    D --> E[Service configuration]
    E --> F[Connectivity troubleshooting]
    F --> G[Validated checkpoint]
```

## Contents

The `.pkt` files represent successive exercise checkpoints:

- `teixei_t_etape1.pkt` through `teixei_t_etape5.pkt`
- `teixei_t_etape6.pkt` through `teixei_t_etape10.pkt`
- `teixei_t_etape11.pkt` through `teixei_t_etape13.pkt`

File names preserve the original course progression and make it possible to review the network state at each stage.

## How to Use

1. Install a compatible version of Cisco Packet Tracer.
2. Clone or download this repository.
3. Open the required `.pkt` checkpoint.
4. Inspect the topology and device configuration.
5. Test connectivity and compare the result with the expected exercise stage.

```bash
git clone https://github.com/TeixeiraThomas/Reseau-Packet-Tracer.git
```

## Topics Covered

Depending on the exercise stage, the labs cover topology design, IPv4 addressing, switching, routing, device configuration and connectivity troubleshooting.
